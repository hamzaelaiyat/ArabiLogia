<h1 align="center">منصة عربيلوجيا</h1>

تطبيق Flutter لتعلم اللغة العربية، يتضمن القواعد النحوية، الصرف، الأدب، الشعر، وتمارين فهم القراءة لطلاب المرحلة الثانوية.

## المميزات

- **المصادقة** - تسجيل المستخدمين وتسجيل الدخول بالبريد الإلكتروني/كلمة المرور، اختيار الصف، الموافقة على الشروط
- **فئات الاختبارات**:
  - النحو
  - الصرف
  - الأدب
  - الشعر
  - القراءة
  - النصوص
- **لوحة التحكم** - الأقسام الرئيسية: الرئيسية، المحاضرات، لوحة المتصدرين، الملف الشخصي، والإعدادات
- **نظام الاختبارات** - اختبارات تفاعلية بأنواع أسئلة متعددة، مؤقت، نتائج فورية، معاينة سريعة
- **نظام المحاضرات** - محاضرات فيديو مع تكامل YouTube، اختبارات تدريبية، وكتل محتوى
- **سجل النشاط** - تتبع الاختبارات المنجزة والأداء عبر الزمن
- **الإعدادات** - تخصيص السمة (فاتح/داكن/النظام)، الإشعارات، الخصوصية، وضع البطاطا
- **واجهة ثنائية اللغة** - واجهة عربية كاملة مع دعم RTL (من اليمين إلى اليسار)
- **ميزات الهاتف** - الإشعارات الفورية، مشاركة النتائج، التحديثات داخل التطبيق

## التقنيات

- **إطار العمل**: Flutter 3.x
- **اللغة**: Dart 3.x
- **إدارة الحالة**: Provider
- **التوجيه**: GoRouter
- **الخلفية**: Supabase (المصادقة، قاعدة البيانات)
- **البنية**: بنية نظيفة تعتمد على الميزات

## البدء

### المتطلبات

- Flutter SDK 3.x
- Dart 3.x
- حساب Supabase

### التثبيت

1. استنساخ المستودع:
   
   ```bash
   git clone https://github.com/hamzaelaiyat/ArabiLogia.git
   cd ArabiLogia
   ```

2. تثبيت التبعيات:
   
   ```bash
   flutter pub get
   ```

3. إعداد Supabase:
   
   - إنشاء مشروع Supabase
   
   - نسخ `.env.example` إلى `.env`:
     ```bash
     cp .env.example .env
     ```
   
   - تحديث `.env` ببيانات Supabase:
     ```
     SUPABASE_URL=https://your-project.supabase.co
     SUPABASE_ANON_KEY=your-anon-key
     ```

4. تشغيل التطبيق:
   
   ```bash
   flutter run
   ```

### البناء للإصدار

```bash
flutter build apk --release --split-per-abi  # ملفات APK (arm64-v8a, armeabi-v7a, x86_64)
flutter build linux --release                 # .tar.xz
flutter build web --release                   # ويب (Vercel)
```

## هيكل المشروع

```
lib/
├── core/
│   ├── config/         # إعداد Supabase
│   ├── constants/      # سلاسل التطبيق، المسارات، المحتوى القانوني
│   ├── routes/         # توجيه التطبيق (GoRouter)
│   ├── services/       # خدمات API (Supabase، الإشعارات، إلخ)
│   ├── theme/          # إعداد السمة (فاتح/داكن/الرموز)
│   └── widgets/        # أدوات مشتركة (مكونات زجاجية، إعلانات أصلية)
├── features/
│   ├── auth/           # تسجيل الدخول، التسجيل، نسيت كلمة المرور
│   ├── dashboard/      # التطبيق الرئيسي (الرئيسية، الاختبارات، المحاضرات، المتصدرين، الملف الشخصي، السجل)
│   └── legal/          # المحتوى القانوني
├── providers/          # إدارة الحالة بـ Provider
└── main.dart           # نقطة دخول التطبيق
```
